🌟 1. The Five Foundational Properties of the Ge'ez Writing System (Overview)

As formulated in Biruk Tesfaye's (2019) thesis, Ge'ez transcends ordinary grammatical scripts by synthesizing five core intellectual properties into a unified cosmological, mathematical, and linguistic framework:

🎨
1. Pictographic
Derived from "images drawn or adapted from nature and the peoples' relation to it". Natural prototypes evolved into stylized proto-graphs and classical fidels.
💡
2. Ideographic
Syllographs symbolize moral, philosophical, and social orders. Consonant classes convey civic and theological values (e.g. Re'es = leadership, Bèt = shelter).
🌌
3. Astrographic
Charting of the stars and the Ethiopian solar calendar: 26 classes × 7 variations = 182 syllographs directly model one 182-day equinox (182 + 182 = 364-day solar year).
🔢
4. Numerological
Discrete Gematria values spanning 1 to 5600. The 7 concentric radial rings multiply each consonant's base value (1×B ... 7×B), encoding mathematical keys.
📜
5. Syllagraphic
Complete Abugida phonetics with innate vocalic markers combined with the Mokshe Fidelat (ሞክሼ ፊደላት) homophone disambiguation property.

📜 6. Syllagraphic Property & Mokshe Fidelat

Ge'ez is a syllabic script (Abugida) where each glyph contains an innate vowel. In Ge'ez grammar and linguistics, ሞክሼ ፊደላት (Mokshe Fidelat — Homophonous Letters) refer to distinct characters that share similar acoustic phonetics in modern vernacular, but encode completely separate semantic, theological, and morphological meanings:

1. The "H" Shifts (ሀ፣ ሐ፣ ኀ)
  • ሀ (ሃሌታው ሀ): Named after ሃሌ (Hallelujah / Praise). Primal existence (e.g. ሀለወ - to exist).
  • ሐ (ሐመሩ ሐ): Named after ሐመር (Ship / Ark). Oceanic life and navigation.
  • ኀ (ብዙኃኑ ኀ / ኀርሙ ኀ): Named after ብዙኃን (abundance / the masses) or ኀርም (net).
  • Example: ኀለየ (To praise / thank) vs. ሐለየ (To think / ponder).
2. The "S" Shifts (ሰ፣ ሠ)
  • ሰ (እሳቱ ሰ): Named after እሳት (Fire). Thermal energy and physical craft.
  • ሠ (ንጉሡ ሠ): Named after ንጉሥ (King / Royal governance). Dawn and celestial sovereignty (e.g. ሠረቀ - to dawn).
  • Example: ሰረቀ (To climb / ascend) vs. ሠረቀ (To steal / purloin).
3. The "A" Shifts (አ፣ ዐ)
  • አ (አሌፉ አ): Named after አሌፍ (Alpha / Origin). Primal source and inception.
  • ዐ (ዓይኑ ዐ): Named after ዓይን (Eye / Vision). Vision, understanding, and living water springs.
  • Example: አመተ (Female servant) vs. ዐመተ (Year / Century / Era).
4. The "Ts" Shifts (ጸ፣ ፀ)
  • ጸ (ጸሎቱ ጸ): Named after ጸሎት (Prayer / Petition). Spiritual supplication.
  • ፀ (ፀሐዩ ፀ): Named after ፀሐይ (Sun / Radiant solar body). Cosmic radiance.
  • Example: ፈጸመ (To complete / execute) vs. ፈፀመ (To pluck out / strip bare).

🧠 7. RNN State Machine Formulation (DFA Model)

Biruk Tesfaye's (2019) algorithm formulates the Ge'ez cipher as a Deterministic Finite Automaton (DFA) state machine over the binary alphabet A = {0, 1}. At each recursion step trₖ (for k ∈ [1..8]): 

V[ti] = (W[ti] · X[ti]) + B[ti]
A[ti] = 1   if V[ti] > 0   else   0
State Feedback Loop: X[tr+1] = A[tr]
Ciphertext Output: C = [A(tr1) || A(tr2) || ... || A(tr8)]

8×8 Cognitive Mapping & Flag Bits

Each character is represented as an 8×8 grid (64 bits). Columns 1 and 2, as well as Row 8, are designated as flag bits (reserved as 0s). The remaining 42 active bits encode the character's unique structural topology.

Key Management & Key Scalability

The symmetric key is defined by the 64-bit Weight matrix (W) and 64-bit Bias matrix (B), yielding a standard 128-bit key size per character. Scalable hidden layers permit key sizes extending up to 512 bits.
